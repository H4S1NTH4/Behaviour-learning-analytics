Interaction Data Logging: The module's foundation is a sophisticated data capture system integrated within a browser-based IDE. It meticulously logs a high-fidelity stream of user interactions, including keystroke dynamics, cursor movements, paste events, idle durations, and compilation/execution sequences. This granular data serves as the basis for all subsequent analytical functions.

Continuous Identity Verification via Keystroke Biometrics: To ensure authorship and prevent impersonation, the module implements a passive authentication system based on keystroke dynamics. It establishes a unique biometric profile for each user by modeling their intrinsic typing rhythm and patterns. Real-time activity is continuously compared against this profile to verify the user's identity throughout the coding session.

Real-Time Struggle Detection and Intervention: The module leverages a Long Short-Term Memory (LSTM) neural network to perform real-time analysis of the incoming interaction data. This model is trained to identify behavioral patterns that are highly correlated with cognitive struggle, such as frequent error-correction cycles, prolonged inactivity, or inefficient coding strategies. Upon detection of such patterns, the system can autonomously trigger pedagogical interventions to provide timely support.

Forensic Analysis and Academic Integrity Assurance: The module provides instructors with two key forensic tools. First, a High-Fidelity Session Playback feature allows for the complete, time-accurate reconstruction of a student's coding session, offering unambiguous insight into the development process. Second, the system programmatically identifies and flags large paste events, compelling the student to provide a formal annotation of the code's source and purpose. This enforces a reflective learning practice and serves as a strong deterrent to academic dishonesty.
